# evroc Security Policy

At evroc, security is non-negotiable. In a world where digital infrastructure powers everything from public services to private innovation, protecting data is a fundamental responsibility — and a cornerstone of trust.

## Reporting a vulnerability

Security vulnerabilities should be reported to [`security@evroc.com`](mailto:security@evroc.com). Do not open a public issue, since this could expose users to security issues that does not yet have a patch.

Make sure to include affected versions, steps to reproduce, and security impact in the report.

### PGP encryption

Vulnerability reports may optionally be encrypted with our [PGP key](https://evroc.com/pgp-key.txt).

### Bug bounty program

evroc does not currently operate a bug bounty program. We do not offer monetary rewards for vulnerability reports. We appreciate coordinated disclosure and may acknowledge contributors in our release notes (with permission), but submitting a report does not guarantee or imply any monetary compensation.

### Vulnerability response

Each report is acknowledged and analyzed by evroc security team within 3 working days. The reporter will be kept updated as the issue is triaged, fixed and released.

## Supported versions

Security patches will be provided for the latest major version. Older versions will not receive retroactive security patches.
